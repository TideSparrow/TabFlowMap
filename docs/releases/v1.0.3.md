Fixes a content-script startup error that could prevent copied words from being linked to their source tab. Language initialization now tolerates a document whose HTML root has not been created yet, and source capture starts without waiting for the saved language setting.

Adds regression coverage for startup before the document root exists, delayed language reads, and words copied from page text and used in a new tab through the address bar or a Google search field.
