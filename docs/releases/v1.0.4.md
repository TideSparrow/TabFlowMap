Fixes tab switching getting stuck when a page does not respond to scroll-position messages. Capturing the current page's position now waits at most 250 milliseconds, and restoring the target page's position no longer blocks subsequent commands. The separate map window keeps its existing focus behavior.

Adds five regression tests covering unresponsive source and target pages, responsive position capture, late replies and missing content scripts. All 232 tests, TypeScript checks, the source audit and production packaging pass locally.
