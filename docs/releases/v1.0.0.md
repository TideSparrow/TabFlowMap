Tab Flow Map's first public release adds a connected view alongside your browser's native tabs, groups and bookmarks.

Start recording and browse normally: links opened in new tabs become source branches. Copy a keyword or URL from a page and use it in a new tab; matching searches, pastes and visits connect back to the source without operating the map for each step.

- Compact, Detailed and Tree views.
- Side panel, separate window and page overlay.
- Search, notes, manual source adjustments, pinned tabs and undo.
- Browser tab restoration and restart recovery.
- English, Simplified Chinese and Japanese.
- Local browser storage, with no extension account, analytics or backend.

## Downloads

- **`tab-flow-map-1.0.0-chrome.zip`** — the extension for Chrome and Chromium-based Edge. Unzip it, open your browser's Extensions page, enable Developer mode, choose **Load unpacked**, and select the folder containing `manifest.json`.
- **`tab-flow-map-1.0.0-sources.zip`** — source code, tests, lockfile, build configuration, screenshots and documentation. Requires Node.js 22.12+ and the pnpm version pinned in `package.json`. Run `pnpm install --frozen-lockfile`, then `pnpm build`.
- **`SHA256SUMS.txt`** — SHA-256 checksums for both ZIPs.
