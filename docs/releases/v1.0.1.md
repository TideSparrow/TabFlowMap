Fixes a blank page overlay observed on a real shopping page: the host environment added an empty `srcdoc` attribute to the extension iframe, overriding its bundled page URL.

- Recover automatically from this interference, with bounded attempts to avoid repeated reloads.
- Show a localized retry message when an overlay cannot finish loading.
- Keep map windows rendering while saved language preferences load, and fall back to the browser language if that read fails.
- Show a localized recovery action if the map UI encounters a rendering error.
- Add regression coverage for frame interference, readiness validation, cleanup, timeouts, language-read failures and render failures.

The extension's permissions and local data format are unchanged. Existing workflows and notes are retained. Chrome Web Store review is separate from this release.

See the [actual Chrome verification](../verification/v1.0.1.md), including separate-window refresh/reopen checks and deliberate overlay interference tests.
