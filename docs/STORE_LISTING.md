## English

**Short description:**

```text
Map your browser tabs into connected workflows. Organize tasks, follow sources, and restore your browsing context locally.
```

**Detailed description — ready to copy:**

```text
Tab Flow Map automatically connects browser tabs to the pages they came from, so you can follow research branches and find your way back to the original question.

You start with one question, follow a review, compare another product, and open a dozen more tabs. Everything is still there, but the thread that connected it is gone. The map keeps those connections visible while you continue browsing.

Browse normally. Branches form automatically.

Start recording, then keep working on your websites:
• Open a link in a new tab: the new page becomes a child branch of its source.
• Copy a keyword or phrase, open a new tab, then paste it into a supported address-bar search or a website's search field: matching content connects the new tab back to its source.
• Copy a URL, open a new tab, then paste it into the address bar and visit it: a matching destination connects back to the source.

You do not need to return to the map, click “+”, or draw a connection for every new tab. Explore normally, then look at the map when you need context or want to return to a source page.

An extra view for clearer thinking

Keep using your browser's native tab bar, tab groups, pinned tabs and bookmarks. Tab Flow Map adds a connected view alongside them, helping you see why you opened a page and where to continue.

• Compact view for an overview, Detailed for notes and context, and Tree for deeper hierarchies.
• Side panel, separate window or page overlay to fit your workspace.
• Search, return to source, pinned-tab management, manual source adjustments and undo for supported actions.
• English, Simplified Chinese and Japanese, with a language selector in settings.

Use it for product research, comparing purchases, technical references or planning a trip. A separate map window can also sit beside your reading window on a second display.

Local data, free and open source

Maps, notes, scroll positions and preferences stay in your browser. The extension has no account system, analytics or backend. Normal website visits and searches still make ordinary browser requests.

Copy-based source matching is limited to the new tab's first three tracked actions. Copying text and opening an unused blank tab alone does not establish a branch. Navigating within an existing tab updates its node; the map is not a permanent browsing-history archive. Deleting a branch closes its ordinary tabs.

Find the project on GitHub

Tab Flow Map is free and open source under the MIT license. Visit GitHub for source code, real screenshots, usage tips, a Mac + iPad workspace idea, installation instructions and updates.

Project and source code:

```

## Single purpose and permissions

Use [PRIVACY_FORM.md](PRIVACY_FORM.md) for copy-ready explanations for each Privacy practices form field, remote-code selection and data-type disclosures. Local processing still needs to be disclosed.

**Single purpose:** Visually organize browser tabs and their source relationships to help users follow research and return to its starting point.

| Permission | Why it is used |
| --- | --- |
| `tabs` | Read tab titles, URLs and state; focus, create, close and manage the tabs represented in the map. |
| `webNavigation` | Identify actual source tabs when websites open new tabs, and update relationships as pages navigate. |
| `storage` | Store maps, notes, preferences and positions locally; keep live bindings and undo state in browser session storage. |
| `sessions` | Reconnect supported browser-restored tabs with their saved map context. |
| `favicon` | Display site icons beside tab nodes. |
| `sidePanel` | Show the map beside the current website. |
| `clipboardRead`, `clipboardWrite` | Read clipboard text when the user chooses Paste in the map menu, and copy a tab URL when the user requests it. Clipboard text is handled locally. |
| HTTP(S) host access | Capture page copy/paste events, save and restore scroll positions, and show the optional map overlay on ordinary websites. |

No remotely hosted executable code is used. Do not upload signing keys, environment files, browser profiles or store credentials.

Use [PRIVACY.md](../PRIVACY.md) when answering data-handling fields. The extension handles tab URLs/titles, short source-related copied text, notes and positions locally; do not describe it as having no data access. It does not send that map data to an extension backend.
