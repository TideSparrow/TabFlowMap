# Third-party notices

Tab Flow Map bundles open-source libraries. Their licenses are separate from this repository's MIT license. Full license texts for bundled runtime dependencies are in `public/THIRD_PARTY_LICENSES.txt` and are also included in the extension package.

Direct runtime dependencies: React, React DOM, React Flow (`@xyflow/react`), Radix Tooltip and Lucide React. The exact versions and transitive dependencies are recorded in `pnpm-lock.yaml`. Keep React Flow's on-canvas attribution visible. Development tools such as WXT, TypeScript and Vitest retain their own upstream licenses.
